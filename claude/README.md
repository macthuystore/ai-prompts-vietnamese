# 🧠 Prompt Claude tiếng Việt

Thư viện prompt tiếng Việt dành cho **Claude**, tập trung vào làm việc với tài liệu dài, phân tích có cấu trúc và biên tập chuyên sâu.

Các prompt được thiết kế để người mới có thể sao chép, thay nội dung trong dấu `[ ]` và sử dụng ngay. Mỗi chuyên mục đều có prompt cơ bản, prompt nâng cao và checklist kiểm tra.

## Danh mục

| Chuyên mục | Nội dung |
|---|---|
| [Người mới bắt đầu](./beginner/) | Đặt câu hỏi, cung cấp bối cảnh và kiểm tra câu trả lời |
| [Content Marketing](./content-marketing/) | Lên ý tưởng, viết nội dung và duy trì giọng thương hiệu |
| [SEO](./seo/) | Nghiên cứu ý định tìm kiếm, lập dàn ý và biên tập nội dung hữu ích |
| [Image & Video Editor](./editor/) | Tạo ý tưởng, storyboard, shot list và kế hoạch dựng |
| [Design](./design/) | Creative brief, concept, nhận diện, bố cục và ui/ux |
| [Văn phòng](./office/) | Email, biên bản, báo cáo và kế hoạch công việc |
| [Giáo dục](./education/) | Giải thích kiến thức, bài học và câu hỏi luyện tập |
| [Lập trình](./programming/) | Phân tích yêu cầu, giải thích và kiểm tra mã nguồn |
| [Kinh doanh](./business/) | Phân tích khách hàng, quy trình và kế hoạch kinh doanh |
| [Phân tích tài liệu](./document-analysis/) | Tóm tắt, đối chiếu và trích xuất dữ liệu từ tài liệu dài |

## Cách sử dụng

1. Chọn chuyên mục phù hợp.
2. Sao chép prompt.
3. Thay nội dung trong dấu `[ ]`.
4. Cung cấp tệp hoặc dữ liệu cần thiết.
5. Kiểm tra kết quả trước khi sử dụng.

## Công thức chung

```text
VAI TRÒ + MỤC TIÊU + BỐI CẢNH + DỮ LIỆU
+ YÊU CẦU + GIỚI HẠN + ĐỊNH DẠNG + KIỂM TRA
```

## Nguyên tắc an toàn

- Không gửi mật khẩu, mã OTP, khóa API hoặc dữ liệu nhạy cảm.
- Không yêu cầu AI tự tạo số liệu, nguồn hoặc trải nghiệm cá nhân.
- Phân biệt rõ dữ kiện, suy luận và đề xuất.
- Kiểm tra lại thông tin quan trọng bằng nguồn đáng tin cậy.
- Tuân thủ bản quyền và quy định công khai việc sử dụng AI.

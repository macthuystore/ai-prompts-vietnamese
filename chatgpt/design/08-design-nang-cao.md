# 08. Prompt Design nâng cao

Phần này giúp Designer quản lý quy trình từ khi tiếp nhận yêu cầu đến khi
bàn giao sản phẩm cuối cùng.

---

## 1. Quy trình thiết kế hoàn chỉnh

```text
Bạn là Design Project Manager.

Hãy xây dựng quy trình cho dự án [TÊN DỰ ÁN].

Thông tin:
- Mục tiêu: [MỤC TIÊU]
- Sản phẩm bàn giao: [DELIVERABLES]
- Nhân sự: [NHÂN SỰ]
- Phần mềm: [PHẦN MỀM]
- Thời hạn: [THỜI HẠN]
- Ngân sách: [NGÂN SÁCH]

Quy trình gồm:
1. Tiếp nhận yêu cầu
2. Làm rõ thông tin
3. Nghiên cứu
4. Creative Brief
5. Phát triển concept
6. Chọn hướng thiết kế
7. Tạo bản nháp
8. Nhận phản hồi
9. Chỉnh sửa
10. Kiểm tra chất lượng
11. Xuất file
12. Bàn giao
13. Lưu trữ

Với mỗi bước, ghi rõ:
- Người phụ trách
- Đầu vào
- Đầu ra
- Thời gian
- Tiêu chí hoàn thành
```

---

## 2. Phân tích phản hồi

```text
Dưới đây là phản hồi của khách hàng:

[DÁN PHẢN HỒI]

Hãy phân loại:
- Nội dung cần sửa
- Màu sắc
- Font chữ
- Hình ảnh
- Bố cục
- Yêu cầu chưa rõ
- Yêu cầu mâu thuẫn
- Yêu cầu ngoài phạm vi ban đầu

Sau đó tạo:
1. Danh sách câu hỏi cần xác nhận
2. Danh sách công việc theo mức độ ưu tiên
3. Bản tóm tắt phản hồi để gửi lại khách hàng
```

---

## 3. Trình bày concept với khách hàng

```text
Hãy giúp tôi trình bày concept thiết kế [TÊN CONCEPT].

Thông tin:
- Mục tiêu: [MỤC TIÊU]
- Ý tưởng: [Ý TƯỞNG]
- Khán giả: [KHÁN GIẢ]
- Màu sắc: [MÀU SẮC]
- Font chữ: [FONT]
- Bố cục: [BỐ CỤC]
- Ứng dụng: [ỨNG DỤNG]

Hãy trình bày:
- Vấn đề cần giải quyết
- Ý tưởng trung tâm
- Lý do lựa chọn
- Cách đáp ứng mục tiêu
- Ví dụ ứng dụng
- Điểm cần khách hàng xác nhận

Không sử dụng thuật ngữ thiết kế quá khó hiểu.
```

---

## 4. Tổ chức file dự án

```text
Hãy đề xuất cấu trúc thư mục cho dự án thiết kế [TÊN DỰ ÁN].

Cần quản lý:
- Brief
- Tài liệu tham khảo
- Nội dung
- Hình ảnh
- Font
- File làm việc
- Bản nháp
- Phản hồi
- File hoàn chỉnh
- File in
- File web
- Giấy phép tài sản

Đề xuất thêm:
- Quy tắc đặt tên
- Cách đánh số phiên bản
- Quy trình sao lưu
- Danh sách file bàn giao
```

---

## 5. Prompt tổng hợp nâng cao

```text
Bạn là Creative Director và Design Project Manager.

Hãy hỗ trợ dự án:

[TÊN DỰ ÁN]

Bối cảnh:
[BỐI CẢNH]

Mục tiêu:
[MỤC TIÊU]

Khán giả:
[KHÁN GIẢ]

Nguồn lực:
[NGUỒN LỰC]

Thực hiện theo từng bước:

Bước 1: Phân tích yêu cầu.
Bước 2: Hỏi tối đa 7 câu quan trọng.
Bước 3: Tạo Creative Brief.
Bước 4: Đề xuất 3 concept.
Bước 5: Chờ tôi chọn concept.
Bước 6: Phát triển màu sắc, font và bố cục.
Bước 7: Lập danh sách sản phẩm bàn giao.
Bước 8: Tạo checklist kiểm tra.
Bước 9: Đề xuất cách trình bày với khách hàng.

Không chuyển sang bước tiếp theo nếu tôi chưa xác nhận.
Không tự suy đoán thông tin còn thiếu.
```

---

## Checklist trước khi bàn giao

- [ ] Đúng Creative Brief
- [ ] Đúng kích thước
- [ ] Đúng màu thương hiệu
- [ ] Chính tả đã được kiểm tra
- [ ] Hình ảnh đủ độ phân giải
- [ ] Font có quyền sử dụng phù hợp
- [ ] Logo đúng phiên bản
- [ ] Bố cục dễ đọc
- [ ] File được đặt tên rõ ràng
- [ ] Có file làm việc và file xuất
- [ ] Tài sản bản quyền được lưu
- [ ] Phiên bản cuối đã được phê duyệt
- [ ] File bàn giao mở được bình thường

# 🤖 Prompt ChatGPT tiếng Việt

Thư mục này tổng hợp những prompt ChatGPT hữu ích dành cho người mới
và người muốn ứng dụng AI vào công việc thực tế.

Các prompt đều được thiết kế để bạn có thể:

- Hiểu nhanh mục đích sử dụng
- Sao chép và dùng ngay
- Dễ dàng thay đổi thông tin
- Xem ví dụ minh họa
- Học thêm cách sử dụng nâng cao

## 🚀 Cách sử dụng prompt

1. Chọn danh mục phù hợp với công việc.
2. Mở file prompt bạn muốn sử dụng.
3. Sao chép phần nằm trong khối mã.
4. Thay nội dung trong dấu `[ ]`.
5. Dán prompt vào ChatGPT.
6. Kiểm tra và điều chỉnh kết quả.

Ví dụ, hãy thay:

```text
[TÊN SẢN PHẨM]
```

thành:

```text
Trâm cài tóc thủ công Tịnh Liên
```

## 🧩 Công thức prompt cơ bản

```text
Bạn là [VAI TRÒ].

Hãy thực hiện [NHIỆM VỤ].

Thông tin:
- Chủ đề: [CHỦ ĐỀ]
- Đối tượng: [ĐỐI TƯỢNG]
- Mục tiêu: [MỤC TIÊU]

Yêu cầu:
- Giọng văn: [GIỌNG VĂN]
- Độ dài: [ĐỘ DÀI]
- Định dạng: [ĐỊNH DẠNG KẾT QUẢ]

Nếu thiếu thông tin quan trọng, hãy hỏi tôi trước khi thực hiện.
```

---

## 💡 Mẹo nâng cao

Thêm yêu cầu sau vào cuối prompt để cải thiện kết quả:

```text
Trước khi trả lời:

1. Phân tích mục tiêu của yêu cầu.
2. Xác định những thông tin còn thiếu.
3. Hỏi tôi tối đa 3 câu hỏi nếu cần.
4. Sau khi hoàn thành, tự kiểm tra kết quả.
5. Đề xuất một phiên bản tốt hơn nếu có.
```

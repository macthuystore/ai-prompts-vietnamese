# 04. Prompt tạo hình ảnh AI

ChatGPT có thể giúp bạn chuyển ý tưởng thành prompt dành cho công cụ tạo ảnh AI.

---

## 1. Công thức prompt hình ảnh

```text
CHỦ THỂ + HÀNH ĐỘNG + BỐI CẢNH + BỐ CỤC + ÁNH SÁNG
+ MÀU SẮC + PHONG CÁCH + GÓC MÁY + THÔNG SỐ ĐẦU RA
```

---

## 2. Tạo prompt từ ý tưởng

```text
Bạn là chuyên gia viết prompt hình ảnh.

Hãy chuyển ý tưởng dưới đây thành một prompt tạo ảnh chi tiết.

Ý tưởng:
[MÔ TẢ Ý TƯỞNG]

Thông tin:
- Chủ thể: [CHỦ THỂ]
- Bối cảnh: [BỐI CẢNH]
- Bố cục: [BỐ CỤC]
- Ánh sáng: [ÁNH SÁNG]
- Màu sắc: [MÀU SẮC]
- Góc máy: [GÓC MÁY]
- Phong cách: [PHONG CÁCH]
- Tỷ lệ: [TỶ LỆ]

Kết quả gồm:
1. Prompt tiếng Việt
2. Prompt tiếng Anh
3. Negative Prompt nếu công cụ hỗ trợ
4. Ba biến thể sáng tạo
```

---

## 3. Prompt ảnh sản phẩm

```text
Hãy viết prompt tạo ảnh quảng cáo cho [SẢN PHẨM].

Yêu cầu:
- Sản phẩm là chủ thể chính
- Mô tả chính xác hình dáng và chất liệu
- Không thay đổi logo
- Không tạo thêm chi tiết không tồn tại
- Bố cục phù hợp với [NỀN TẢNG]
- Chừa khoảng trống để đặt chữ
- Ánh sáng [PHONG CÁCH ÁNH SÁNG]
- Màu chủ đạo [MÀU SẮC]
- Tỷ lệ [TỶ LỆ]
```

---

## 4. Prompt ảnh từ hình tham chiếu

```text
Tôi sẽ cung cấp một hình ảnh tham chiếu.

Hãy phân tích:
- Chủ thể
- Bố cục
- Ánh sáng
- Màu sắc
- Góc máy
- Độ sâu trường ảnh
- Bề mặt và chất liệu
- Cảm xúc

Sau đó viết prompt tạo một hình ảnh mới lấy cảm hứng từ các đặc điểm trên.

Không sao chép logo, nhân vật, tác phẩm hoặc yếu tố nhận diện có bản quyền.
```

---

## 5. Kiểm tra prompt hình ảnh

```text
Hãy kiểm tra prompt hình ảnh dưới đây.

Xác định:
- Yêu cầu bị mâu thuẫn
- Chi tiết chưa rõ
- Từ ngữ không tạo giá trị
- Thông số còn thiếu
- Rủi ro làm sai sản phẩm
- Rủi ro liên quan đến bản quyền

Sau đó tạo một phiên bản rõ ràng và ngắn gọn hơn.

Prompt:
[DÁN PROMPT]
```

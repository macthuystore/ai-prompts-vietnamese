# ✨ Prompt Gemini tiếng Việt

Thư viện prompt tiếng Việt dành cho **Gemini**, tập trung vào phân tích đa phương tiện, làm việc với tệp và các tính năng trong hệ sinh thái Google.

Các prompt được thiết kế để người mới có thể sao chép, thay nội dung trong dấu `[ ]` và sử dụng ngay. Mỗi chuyên mục đều có prompt cơ bản, prompt nâng cao và checklist kiểm tra.

## Danh mục

| Chuyên mục | Nội dung |
|---|---|
| [Người mới bắt đầu](./beginner/) | Đặt câu hỏi, tải tệp và kiểm tra kết quả |
| [Content Marketing](./content-marketing/) | Lên ý tưởng và chuyển đổi nội dung đa nền tảng |
| [SEO](./seo/) | Phân tích ý định tìm kiếm, dữ liệu và nội dung website |
| [Image & Video Editor](./editor/) | Phân tích ảnh, video, storyboard và kế hoạch dựng |
| [Design](./design/) | Concept, bố cục, màu sắc, thương hiệu và giao diện |
| [Văn phòng](./office/) | Tài liệu, email, bảng dữ liệu và kế hoạch |
| [Giáo dục](./education/) | Bài học, bài tập, quiz và giải thích kiến thức |
| [Lập trình](./programming/) | Phân tích code, repository và xây dựng ứng dụng |
| [Kinh doanh](./business/) | Nghiên cứu, phân tích và lập kế hoạch |

## Cách sử dụng

1. Chọn chuyên mục phù hợp.
2. Sao chép prompt.
3. Thay nội dung trong dấu `[ ]`.
4. Cung cấp tệp hoặc dữ liệu cần thiết.
5. Kiểm tra kết quả trước khi sử dụng.

## Công thức chung

```text
VAI TRÒ + MỤC TIÊU + BỐI CẢNH + DỮ LIỆU
+ YÊU CẦU + GIỚI HẠN + ĐỊNH DẠNG + KIỂM TRA
```

## Nguyên tắc an toàn

- Không gửi mật khẩu, mã OTP, khóa API hoặc dữ liệu nhạy cảm.
- Không yêu cầu AI tự tạo số liệu, nguồn hoặc trải nghiệm cá nhân.
- Phân biệt rõ dữ kiện, suy luận và đề xuất.
- Kiểm tra lại thông tin quan trọng bằng nguồn đáng tin cậy.
- Tuân thủ bản quyền và quy định công khai việc sử dụng AI.
